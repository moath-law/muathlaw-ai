# 🔄 مطابقة الجلسات

**قارن جلساتك في ناجز بتقويمك أو نظام مكتبك، واكتشف الجلسة الناقصة قبل أن تفوتك.**

📥 **[تحميل المهارة (ملف zip)](https://github.com/moath-law/muathlaw-ai/raw/main/dist/session-matcher.zip)** · 🌐 **[الشرح والفيديو على موقعنا](https://muathlaw.com)**

---

## ماذا تفعل؟
1. يقرأ جلسات ناجز (نص منسوخ أو لقطة شاشة أو ملف) وتقويمك (Excel أو CSV أو ملف تقويم).
2. يطابقها برقم القضية والتاريخ، أو تقريبيًا بالوقت والمحكمة والأطراف.
3. يكشف: الجلسات الناقصة، المكررة، المتعارضة في الوقت، والمختلفة في الموعد أو الدائرة أو الرابط.
4. ينشئ ملف تقويم جاهزًا للاستيراد بالجلسات الناقصة مع تنبيهات.

## متى تستخدمها؟
- بداية كل أسبوع للتأكد من اكتمال جدول الجلسات.
- بعد تأجيل عدة جلسات أو تغيير مواعيدها.
- عندما يشترك أكثر من محامٍ في جدول واحد.

## جرّبها
بعد التثبيت، افتح محادثة جديدة في Claude واكتب:
```
طابق جلساتي في ناجز مع هذا الملف (مع إرفاق القائمتين)
```

**مثال على النتيجة (بيانات وهمية):**
```
فحصت 14 جلسة: 11 مطابقة، 3 تحتاج إجراء
➕ ناقصة في التقويم: قضية 47xxxxxxxx — الثلاثاء 10:30 — مرئية
⚠️ مختلفة: قضية 46xxxxxxxx — الوقت في ناجز 09:00 وفي التقويم 11:00
⛔ متعارضة: جلستان الأربعاء 10:00 في محكمتين مختلفتين
```

## التثبيت
**الطريقة الأولى — المهارة وحدها (Claude):**
1. حمّل الملف من الرابط أعلاه: `session-matcher.zip`.
2. افتح Claude ← **الإعدادات (Settings)** ← **Capabilities** ← **Skills**.
3. اضغط **Upload skill** واختر الملف. انتهى.

**الطريقة الثانية — كل أدوات معاذ للمحاماة دفعة واحدة:** اتبع خطوات التثبيت في [الصفحة الرئيسية للمستودع](https://github.com/moath-law/muathlaw-ai#التثبيت-اختر-الأسهل-لك).

## الخصوصية
المهارة تعمل داخل حسابك في Claude فقط. لا ترسل بياناتك أو ملفات موكليك إلينا ولا إلى أي جهة أخرى.
