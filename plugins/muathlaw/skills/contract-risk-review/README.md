# 🛡️ فاحص العقود

**اعرف مخاطر العقد قبل أن يوقّع موكلك: جدول بالبنود الخطرة والناقصة، مع صياغة بديلة جاهزة لكل بند.**

📥 **[تحميل المهارة (ملف zip)](https://github.com/moath-law/muathlaw-ai/raw/main/dist/contract-risk-review.zip)** · 🌐 **[الشرح والفيديو على موقعنا](https://muathlaw.com)**

---

## ماذا تفعل؟
1. يقرأ العقد من جهة الطرف الذي تمثله.
2. يفحص أكثر من 15 محورًا: المقابل، المدة، الشرط الجزائي، الفسخ، المسؤولية، القوة القاهرة، النزاعات وغيرها.
3. يصنّف كل بند: 🔴 خطر، 🟡 يحتاج تعديلًا، 🟢 مقبول، ⬜ غائب.
4. يقترح صياغة بديلة لكل بند، ويضيف البنود الناقصة.

## متى تستخدمها؟
- عميل أرسل عقدًا ويريد رأيك قبل التوقيع اليوم.
- تفاوض على عقد توريد أو مقاولة أو خدمات.
- نزاع قائم وتريد معرفة نقاط القوة والضعف في العقد.

## جرّبها
بعد التثبيت، افتح محادثة جديدة في Claude واكتب:
```
راجع هذا العقد، نحن الطرف الثاني (مع إرفاق العقد)
```

**مثال على النتيجة (بيانات وهمية):**
```
الحكم العام: لا يوقَّع قبل تعديل 3 بنود
🔴 البند 9: شرط جزائي مفتوح بلا سقف ← الصياغة البديلة: «… على ألا يتجاوز مجموع الغرامات 10% من قيمة العقد»
⬜ غائب: آلية استلام الأعمال والاعتراض عليها
```

## التثبيت
**الطريقة الأولى — المهارة وحدها (Claude):**
1. حمّل الملف من الرابط أعلاه: `contract-risk-review.zip`.
2. افتح Claude ← **الإعدادات (Settings)** ← **Capabilities** ← **Skills**.
3. اضغط **Upload skill** واختر الملف. انتهى.

**الطريقة الثانية — كل أدوات معاذ للمحاماة دفعة واحدة:** اتبع خطوات التثبيت في [الصفحة الرئيسية للمستودع](https://github.com/moath-law/muathlaw-ai#التثبيت-اختر-الأسهل-لك).

## الخصوصية
المهارة تعمل داخل حسابك في Claude فقط. لا ترسل بياناتك أو ملفات موكليك إلينا ولا إلى أي جهة أخرى.
