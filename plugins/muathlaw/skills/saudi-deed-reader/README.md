# 📜 قارئ الصكوك

**ارفع صك الحكم أو الملكية أو الوكالة، واحصل على بياناته كاملة في جدول واحد خلال ثوانٍ، مع تنبيهات المحامي.**

📥 **[تحميل المهارة (ملف zip)](https://github.com/moath-law/muathlaw-ai/raw/main/dist/saudi-deed-reader.zip)** · 🌐 **[الشرح والفيديو على موقعنا](https://muathlaw.com)**

---

## ماذا تفعل؟
1. يتعرف على نوع الصك تلقائيًا: حكم، ملكية، وكالة، حصر ورثة، صلح.
2. يستخرج الأطراف والأرقام والتواريخ والمحكمة والدائرة.
3. ينقل منطوق الحكم أو بنود الوكالة بنصها الحرفي.
4. ينبّهك إلى ما يحتاج متابعة: مهلة اعتراض، وكالة قاربت الانتهاء أو تنقصها صلاحية، تهميش رهن أو حجز، تعارض في البيانات.

## متى تستخدمها؟
- وصلك حكم جديد وتريد خلاصته قبل قراءته كاملًا.
- تريد التأكد أن وكالة العميل تشمل الاعتراض والقبض والصلح.
- تراجع صك عقار قبل الإفراغ أو رفع دعوى.
- تحتاج إدخال بيانات الصك في نظام مكتبك بسرعة.

## جرّبها
بعد التثبيت، افتح محادثة جديدة في Claude واكتب:
```
اقرأ هذا الصك واستخرج بياناته (مع إرفاق الصك PDF أو صورة)
```

**مثال على النتيجة (بيانات وهمية):**
```
نوع الصك: صك حكم ابتدائي
المحكمة: المحكمة العامة — الدائرة (…)
المدعي: أحمد عبدالله (وهمي) | المدعى عليه: شركة النموذج للتجارة (وهمية)
المنطوق: «حكمت الدائرة بإلزام المدعى عليها بأن تدفع للمدعي مبلغ 85,000 ريال»
⚠️ تنبيه: حكم ابتدائي — احسب مهلة الاعتراض (30 يومًا من تسلّم الصك)
```

## التثبيت
**الطريقة الأولى — المهارة وحدها (Claude):**
1. حمّل الملف من الرابط أعلاه: `saudi-deed-reader.zip`.
2. افتح Claude ← **الإعدادات (Settings)** ← **Capabilities** ← **Skills**.
3. اضغط **Upload skill** واختر الملف. انتهى.

**الطريقة الثانية — كل أدوات معاذ للمحاماة دفعة واحدة:** اتبع خطوات التثبيت في [الصفحة الرئيسية للمستودع](https://github.com/moath-law/muathlaw-ai#التثبيت-اختر-الأسهل-لك).

## الخصوصية
المهارة تعمل داخل حسابك في Claude فقط. لا ترسل بياناتك أو ملفات موكليك إلينا ولا إلى أي جهة أخرى.

## تنبيه
النتائج مسودة مساعدة للمحامي، وليست استشارة قانونية، وتحتاج مراجعة محامٍ مرخص قبل الاعتماد عليها.
