# 📨 ملخص الملف للعميل

**حوّل محضر الجلسة أو الحكم إلى رسالة واضحة لعميلك يفهمها من أول قراءة، جاهزة للواتساب أو البريد.**

📥 **[تحميل المهارة (ملف zip)](https://github.com/moath-law/muathlaw-ai/raw/main/dist/client-case-summary.zip)** · 🌐 **[الشرح والفيديو على موقعنا](https://muathlaw.com)**

---

## ماذا تفعل؟
1. يبدأ بالأهم: أين وصلت القضية في جملة واحدة.
2. يشرح ما حدث وأثره على العميل بلا مصطلحات.
3. يحدد الخطوة القادمة وموعدها، وما المطلوب من العميل.
4. يعطيك نسختين: قصيرة للواتساب، ومفصلة للبريد أو الطباعة.

## متى تستخدمها؟
- بعد كل جلسة لإبلاغ العميل خلال دقيقة.
- عند صدور حكم وتحتاج شرحه للعميل بهدوء ووضوح.
- عند طلب مستند أو توقيع من العميل بموعد محدد.

## جرّبها
بعد التثبيت، افتح محادثة جديدة في Claude واكتب:
```
اكتب للعميل تحديثًا عن هذه الجلسة (مع إرفاق محضر الجلسة)
```

**مثال على النتيجة (بيانات وهمية):**
```
السلام عليكم أستاذ خالد،
عُقدت جلسة قضيتكم اليوم، وأعطت المحكمة الطرف الآخر مهلة أسبوعين للرد على مطالبتنا.
الجلسة القادمة يوم (…) الساعة 10 صباحًا.
المطلوب منكم: صورة من كشف الحساب البنكي قبل يوم الخميس.
نطمئنكم أولًا بأول.
```

## التثبيت
**الطريقة الأولى — المهارة وحدها (Claude):**
1. حمّل الملف من الرابط أعلاه: `client-case-summary.zip`.
2. افتح Claude ← **الإعدادات (Settings)** ← **Capabilities** ← **Skills**.
3. اضغط **Upload skill** واختر الملف. انتهى.

**الطريقة الثانية — كل أدوات معاذ للمحاماة دفعة واحدة:** اتبع خطوات التثبيت في [الصفحة الرئيسية للمستودع](https://github.com/moath-law/muathlaw-ai#التثبيت-اختر-الأسهل-لك).

## الخصوصية
المهارة تعمل داخل حسابك في Claude فقط. لا ترسل بياناتك أو ملفات موكليك إلينا ولا إلى أي جهة أخرى.

## تنبيه
النتائج مسودة مساعدة للمحامي، وليست استشارة قانونية، وتحتاج مراجعة محامٍ مرخص قبل الاعتماد عليها.
