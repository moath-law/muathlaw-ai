# 💬 محلل الواتساب كدليل

**حوّل محادثة الواتساب إلى دليل مرتب: خط زمني، وإقرارات ووعود بنصها، وتناقضات الخصم — جاهزة للمذكرة.**

📥 **[تحميل المهارة (ملف zip)](https://github.com/moath-law/muathlaw-ai/raw/main/dist/whatsapp-evidence.zip)** · 🌐 **[الشرح والفيديو على موقعنا](https://muathlaw.com)**

---

## ماذا تفعل؟
1. يقرأ ملف تصدير المحادثة أو لقطات الشاشة.
2. يستخرج الإقرارات والوعود والمبالغ والتواريخ بنصها الحرفي ووقتها.
3. يكشف التناقضات بين المحادثة وأقوال الخصم، ويحدد الرسائل التي قد تُستخدم ضد موكلك.
4. يربط كل دليل بطلب من طلبات الدعوى، ويعطيك قائمة جاهزية الدليل وفق نظام الإثبات.

## متى تستخدمها؟
- نزاع مالي أو عمالي أو تجاري معظم أدلته محادثات واتساب.
- الخصم أنكر واقعة ثابتة في المحادثة.
- محادثة طويلة جدًا وتريد أهم ما فيها في دقائق.

## جرّبها
بعد التثبيت، افتح محادثة جديدة في Claude واكتب:
```
حلّل هذه المحادثة واستخرج الإقرارات المتعلقة بالمبلغ (مع إرفاق ملف التصدير)
```

**مثال على النتيجة (بيانات وهمية):**
```
أقوى ما لصالحنا: إقرار صريح بالمبلغ بتاريخ (…)
[14/03 — 21:12] الطرف الثاني: «المبلغ عندي وبحوّله أول الشهر»
← يرتبط بالطلب 1 (إلزام بالسداد) — قيمته: إقرار بالدين ووعد بالسداد
⚠️ تناقض: ادعى في مذكرته أنه لم يستلم البضاعة، وكتب في 02/03: «وصلت البضاعة»
```

## التثبيت
**الطريقة الأولى — المهارة وحدها (Claude):**
1. حمّل الملف من الرابط أعلاه: `whatsapp-evidence.zip`.
2. افتح Claude ← **الإعدادات (Settings)** ← **Capabilities** ← **Skills**.
3. اضغط **Upload skill** واختر الملف. انتهى.

**الطريقة الثانية — كل أدوات معاذ للمحاماة دفعة واحدة:** اتبع خطوات التثبيت في [الصفحة الرئيسية للمستودع](https://github.com/moath-law/muathlaw-ai#التثبيت-اختر-الأسهل-لك).

## الخصوصية
المهارة تعمل داخل حسابك في Claude فقط. لا ترسل بياناتك أو ملفات موكليك إلينا ولا إلى أي جهة أخرى.
