# ✍️ كاتب صحيفة الدعوى

**أعطه الوقائع والمستندات، وخذ صحيفة دعوى مرتبة وجاهزة للصق في ناجز، مع فحص شروط القبول قبل الرفع.**

📥 **[تحميل المهارة (ملف zip)](https://github.com/moath-law/muathlaw-ai/raw/main/dist/lawsuit-statement.zip)** · 🌐 **[الشرح والفيديو على موقعنا](https://muathlaw.com)**

---

## ماذا تفعل؟
1. يجمع البيانات الناقصة بسؤال واحد مختصر.
2. يرتب الوقائع زمنيًا مع الإحالة لكل مستند.
3. يكتب الأسانيد والطلبات بصياغة محددة وقابلة للتنفيذ.
4. يفحص الصحيفة: البيانات النظامية (م41 مرافعات)، الاختصاص، الصفة والمصلحة، الإجراءات السابقة للرفع، مدد سماع الدعوى.

## متى تستخدمها؟
- دعوى مطالبة مالية أو عمالية أو تجارية تريد رفعها بسرعة ودقة.
- تريد مراجعة صحيفة كتبها زميل قبل الرفع.
- عميل أرسل لك الوقائع بلغة عامية وتحتاج تحويلها لصحيفة.

## جرّبها
بعد التثبيت، افتح محادثة جديدة في Claude واكتب:
```
اكتب صحيفة دعوى مطالبة مالية بهذه الوقائع: ...
```

**مثال على النتيجة (بيانات وهمية):**
```
الوقائع:
1. بتاريخ (…) أبرم المدعي مع المدعى عليها عقد توريد (مرفق 1).
2. سلّم المدعي البضاعة كاملة (مرفق 2)، ولم تسدد المدعى عليها المبلغ.
الطلبات:
1. إلزام المدعى عليها بأن تدفع للمدعي مبلغ 120,000 ريال.
فحص ما قبل الرفع: ✅ الاختصاص ✅ الصفة ⚠️ أرفق كشف الحساب
```

## التثبيت
**الطريقة الأولى — المهارة وحدها (Claude):**
1. حمّل الملف من الرابط أعلاه: `lawsuit-statement.zip`.
2. افتح Claude ← **الإعدادات (Settings)** ← **Capabilities** ← **Skills**.
3. اضغط **Upload skill** واختر الملف. انتهى.

**الطريقة الثانية — كل أدوات معاذ للمحاماة دفعة واحدة:** اتبع خطوات التثبيت في [الصفحة الرئيسية للمستودع](https://github.com/moath-law/muathlaw-ai#التثبيت-اختر-الأسهل-لك).

## الخصوصية
المهارة تعمل داخل حسابك في Claude فقط. لا ترسل بياناتك أو ملفات موكليك إلينا ولا إلى أي جهة أخرى.

النتائج مسودة مساعدة للمحامي، وليست استشارة قانونية، وتحتاج مراجعة محامٍ مرخص قبل الاعتماد عليها.
