## التثبيت (اختر الأسهل لك)

### ⓪ الأسرع: اطلبه من Claude نفسه
افتح محادثة جديدة في Claude واكتب:
```
ثبّت لي المكوّن من https://github.com/moath-law/muathlaw-ai
```
يثبّته Claude لك مباشرة إذا كان عنده وصول لمتصفحك (إضافة Claude in Chrome)، وإلا يعطيك الخطوات أدناه.

### ① Claude — المكوّن الكامل (الأدوات + المهارات) ✅ الأفضل
1. افتح [claude.ai](https://claude.ai) ← **Plugins** (المكونات) من القائمة الجانبية.
2. اضغط **Add** ← **Add marketplace**.
3. الصق: `moath-law/muathlaw-ai`
4. ثبّت **muathlaw**. انتهى.

### ② Claude — الموصل فقط (دقيقة واحدة)
**Plugins** ← **Add** ← **Add custom connector**:
- الاسم: `معاذ للمحاماة`
- الرابط: `https://mcp.muathlaw.com/mcp`
- المصادقة: **No sign-in**

### ③ ChatGPT
افتح محادثة جديدة في وضع **العمل** والصق هذه الرسالة كما هي:

```
استخدم Plugin Creator وأنشئ لي مكوّنًا إضافيًا باسم «معاذ للمحاماة» يتصل بخادم MCP على الرابط https://mcp.muathlaw.com/mcp بدون مصادقة، وثبّته في حسابي، ثم جرّبه بالبحث عن «الفصل التعسفي».
```

أو يدويًا من الإعدادات: أضف تطبيق/موصل MCP مخصصًا بالرابط نفسه، والمصادقة: بدون.

### ④ Claude Code
```
/plugin marketplace add moath-law/muathlaw-ai
/plugin install muathlaw@muathlaw
```

النتائج للتوعية وليست استشارة قانونية، ولا تنشئ علاقة محامٍ بموكل. للاستشارات: [muathlaw.com](https://muathlaw.com) — واتساب 0125118667.

## محتوى المستودع
- `plugins/muathlaw/` — المكوّن الإضافي (الموصل + 12 مهارة).
- `dist/` — ملفات zip لتحميل كل مهارة على حدة.
- `server/` — كود خادم MCP (PHP) لمن يريد تشغيل نسخته الخاصة: انسخ المجلد إلى استضافة PHP 8.1+، وأعد تسمية `config.example.php` إلى `config.php` وغيّر `admin_token`، ثم أضف مهمة Cron تشغّل `reindex.php` كل 10 دقائق.
